# Kapis Kushwha | Equity Research Portfolio

Professional e-portfolio microsite for Kapis Kushwha, a PGDM (Financial Management) student building toward an Equity Research Analyst career.

## Contents
- `streamlit_app.py` — Streamlit portfolio microsite
- `requirements.txt` — deployment dependencies
- `assets/profile.png` — professional portfolio photograph
- `assets/resume.pdf` — resume
- Excel workbooks in the repository — valuation, sectoral and mutual-fund analysis evidence

## Deployment
Designed for Streamlit Community Cloud with `streamlit_app.py` as the main file.
